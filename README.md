
# 📊 Student Performance Analytics System

A Python-based application designed to analyze student academic performance and generate meaningful insights.

## 🚀 Features

- Calculate total marks
- Calculate student averages and percentages
- Identify highest and lowest marks
- Compare subject-wise performance
- Generate data visualizations
- Interactive student performance analysis

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit

## 💻 Installation

Install the required libraries:

pip install -r requirements.txt

## ▶️ Run the Application

streamlit run app.py
